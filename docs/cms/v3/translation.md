# CMS v3 — 번역 화면 개선 설계

작성일: 2026-09-29 · 상태: **구현 완료(2026-09-29)** · 브랜치: `claude/editor-layout-toolbar-improvements-47d8e3`

> 지금 구조는 [`v2/b4-i18n.md`](../v2/b4-i18n.md), 처음 메모는 [`CMS-V2-SPEC.md`](../../../CMS-V2-SPEC.md) §8. 이 문서는 사용자와 정한 결정(2026-09-29)과 구현이다.

## 0. 문제

1. 언어 전환(KO 버튼)이 편집 화면 상단바 왼쪽에 있어 찾기 어렵고 자리가 어색하다.
2. 목록에서 원문과 번역본이 각각 다른 줄이라, 같은 글의 KO와 EN이 멀리 떨어져 헷갈린다.
3. 번역할 때 원문을 보면서 쓰기 어렵고, 번역한 뒤 원문이 바뀐 곳을 알 수 없다.

## 1. 결정

| # | 주제 | 결정 |
| --- | --- | --- |
| 1 | 언어 전환 위치 | 상단바의 언어 메뉴를 없애고 **본문 제목 위 언어 탭**(`KO 원문 · EN · + JA`)으로 옮긴다. 탭마다 상태 점을 보인다 |
| 2 | 목록 | **글 하나(번역 묶음)당 한 줄.** 언어 칸에 KO·EN·JA 표시(발행·초안·없음), 누르면 그 언어 편집으로 간다 |
| 3 | 목록 일괄 작업 | 휴지통·보관 등은 **묶음 전체**에 적용한다. 번역본 하나만 지우기는 언어 탭 메뉴의 `이 번역본 삭제`로 한다 |
| 4 | 번역 편집 | 번역본도 **원문과 같은 에디터**(툴바·서식·컴포넌트·MDX 보기)로 자유롭게 쓴다. 블록 구조를 강제하지 않는다 |
| 5 | 원문 보기 | 에디터 왼쪽에 **원문을 실제 글 모양으로 띄운다**(읽기 전용, 따로 스크롤). 접을 수 있고 상태를 기억한다 |
| 6 | 새 번역본 | **원문 복사본**(언어별 값·본문)에서 시작한다. 구조를 그대로 두고 글자만 덮어쓴다 |
| 7 | 원문 변경 | 번역자가 마지막으로 확인한 원문(`baseSource`)과 원문 최신 초안이 다르면 `원문이 바뀌었어요`를 보인다. `비교`는 원문 두 버전을 블록 단위로(바뀜·추가·삭제) 보여 주고, `확인함`은 지금 원문을 확인한 원문으로 남긴다 |
| 8 | 발행 | 원문 변경을 확인하지 않았으면 **경고만** 한다(발행은 된다). 원문이 공개돼야 번역본이 발행되는 v2 규칙은 그대로다 |

## 2. 저장

- `entry_bodies.translation JSONB`(원문은 NULL): `{ version: 2, baseSource }`. working·published가 각자 가지고 발행·가져오기·내보내기가 함께 옮긴다. 내용 해시에는 넣지 않는다.
- 저장 요청(`PATCH /entries/{id}`)의 `translation`은 생략하면 저장된 값을 유지한다(일괄 작업 등). 편집 화면은 폼의 `$translation` 키(JSON 문자열)로 자동 저장·복구본·충돌 비교에 함께 싣는다.
- 원문 두 버전 비교: `src/cms/core/translation/source-diff.ts`(`diffSources`). 원문을 블록으로 나누고(상자는 펼쳐서 제목·탭 이름과 안쪽 블록을 따로) 최장 공통 부분열로 같은 블록을 맞춘 뒤, 같은 자리의 다른 내용은 바뀜, 나머지는 추가·삭제로 본다.
- 운영 DB에는 `pnpm cms:db:migrate`로 열을 더한다(2026-09-29 실행함).

## 3. 화면

- 목록: `GET /entries?group=translation`이 원문 한 줄에 `translations`(휴지통 밖 묶음 콘텐츠)를 담는다. 검색은 묶음 안 어느 언어 제목·주소에 걸려도 되고, 언어 필터는 "이 언어가 있는 글"이다. 휴지통은 항목별 그대로다.
- 묶음 상태 전환: 원문의 보관·보관 해제·휴지통은 번역본에도 적용한다. 원문을 복원하면 함께 버린 번역본만 돌아오고, 원문이 휴지통에 있으면 번역본만 복원할 수 없다(`source_trashed`). 원문을 영구 삭제하면 휴지통의 번역본도 지운다.
- 편집 화면(번역본): 왼쪽 원문 칸(`source-pane.tsx`) + 오른쪽 일반 에디터. 툴바 오른쪽에 `원문`·`MDX` 전환. 좁은 화면은 원문 칸이 덮개로 열린다. 원문 변경 알림 막대와 비교 대화상자(`source-change-dialog.tsx`).
- 에디터 툴바는 폭이 모자라면 도구를 숨기지 않고 여러 줄로 감싼다(원문 칸을 연 때).

## 4. 거쳐 온 방식(버린 것)

같은 날 세 번 바꿨다. 기록으로 남긴다.

1. **블록 단위 나란히 보기**: 원문·번역을 번역 단위(블록)마다 한 줄씩 쌓고 1:1 구조를 강제했다. 콜아웃·탭 모양이 보이지 않아 읽기 어려웠다.
2. **미리보기 + 오른쪽 번역 패널 → 글 안 넓은 띠**: 실제 글 모양 미리보기에서 블록을 누르면 패널(이후 그 자리의 넓은 띠)에서 원문을 보며 번역했다. 쓰는 칸이 블록 하나로 갇혀 에디터 기능(서식·컴포넌트·목록 편집)을 쓸 수 없었다.
3. **지금 방식**: 번역도 일반 에디터로 쓰고 원문은 옆에 띄운다. 블록 대응은 원문 두 버전 비교에만 쓴다.
